# 术语表

| 术语 | 含义 |
|------|------|
| pi-compaction-i18n | 本项目：把 pi 的 `/compact` 压缩摘要与 `/tree` 分支摘要从英文改为本地语言的 Pi 扩展。 |
| compaction | pi 的上下文压缩摘要流程，对应 `/compact` 或自动压缩。 |
| tree summary | pi 在会话树分支切换时生成的分支摘要，对应 `/tree`。 |
| locale | 系统语言地区标识，从环境变量读取（`zh_CN.UTF-8` 归一为 `zh-CN`）。 |
| locale 检测优先级 | `PI_LOCALE` > `LC_ALL` > `LANG`，取第一个非空值。 |
| SupportedLanguage | 摘要语言枚举，共 11 种：`zh-Hans`、`zh-Hant`、`ja`、`ko`、`de`、`fr`、`es`、`pt`、`ru`、`ar`、`en`。 |
| 语言映射 | locale → `SupportedLanguage` 的归一规则；未知语言回退 `en`。 |
| 语言指令 | `languageInstructionForLocale()` 生成的一段英文句子，要求 LLM 用目标语言输出全部标题与正文。 |
| 章节标题矩阵 | `SECTION_LABELS`：每种语言的 9 个小节标题（目标、约束与偏好、进展、已完成、进行中、阻塞项、关键决策、下一步、关键上下文）。 |
| 摘要格式块 | `localizedSummaryFormat()`：把章节标题矩阵渲染进 prompt 的输出格式说明。 |
| 事件拦截 | 扩展注册 `session_before_compact` 与 `session_before_tree`，在 pi 生成摘要前接管。 |
| 事件 precedence | 同一事件多个 handler 时，最后一个返回非 null 结果的 handler 生效；同一时间只应有一个扩展接管压缩。 |
| 配置 | `~/.pi/agent/pi-compaction-i18n.json`，首次使用时自动创建；字段 `locale`（`auto` 或具体 locale）与 `model`（空表示用会话当前模型）。 |
| 模型覆盖 | 配置中 `model` 写 `provider/modelId` 时，用该模型生成摘要，替代会话当前模型。 |
| API key 解析 | 三层回退：`ctx.modelRegistry.getApiKeyAndHeaders()` → 直读 `~/.pi/agent/auth.json` → provider 环境变量。 |
| 回退到 pi 默认 | 拿不到模型或 API key 时返回 undefined，由 pi 走自己的默认压缩流程。 |
| `/compaction-i18n-status` | 自定义命令，输出检测到的 locale、摘要语言与语言指令。 |
